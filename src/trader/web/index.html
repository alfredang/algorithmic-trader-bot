Connect Alpaca paper
  1. alpaca.markets → Paper Trading → API Keys → Generate
  2. Put APCA_API_KEY_ID and APCA_API_SECRET_KEY in .env
  3. Restart the app, then test on Integrations

AI agents (optional)

The multi-agent desk runs with a deterministic rule brain out of the box. To use an LLM:

  • OpenAI Codex - Sign in with ChatGPT (subscription): run codex login on this machine. The app reuses your own local login through the official Codex SDK and never reads or stores tokens.
  • Claude (Claude Agent SDK): set ANTHROPIC_API_KEY. Claude.ai subscription login is not offered: Anthropic's terms do not allow third-party apps to use it.
  • OpenAI Agents SDK: set OPENAI_API_KEY.
