AI agents vs agentic AI

In this app: agentic AI is the capability of AI to plan and call tools, skills, memory and instructions (the analyst desk); an AI agent is a special class of agentic AI that stands by 24/7 and works all the time - for example OpenClaw, Hermes Agent or OpenAI Dots - which is what the Always-on agent mode does.
